## 2. A股（已实现基线）

**代码事实**（以代码为准）：
- 整手：`ATRSizer` 用 `math.floor(qty/100)*100` 截到 100 股；`Instrument.lot_size=100, t_plus=1`
- T+1：可用数量 = 已持仓，当日买入计入冻结（`frozen_qty`），卖出须可用 ≥ 0
- 涨跌停/一字板：见 `docs/03`，默认开启
- 费用：佣金+印花税(仅卖)+过户费，见 `docs/03`

### A股牌号规则（隐含前提，需在 Instrument 配置）
| 板 | 涨跌幅 | 代码 |
|---|---|---|
| 主板 | ±10% | 60/00 |
| 创业板 | ±20% | 30 |
| 科创板 | ±20% | 688 |
| ST/*ST | ±5% | — |

> 当前 `Bar` 的 `flags.is_st` 与涨跌幅判断字段已预留，**股价涨跌幅比例在撮合中未强制**（只做一字板买卖拦截）。如需严格涨跌停价限制需扩展 matcher。

## 3. 期货（设计基线，未实盘跑通）

- 用 `Instrument.multiplier`（合约乘数）、`margin_rate`（保证金）、`expiry_date`（到期）、`open_interest`（持仓量）
- `calc_notional = price*qty*multiplier`；`calc_margin = notional*margin_rate`
- T+0、可做空（`shortable=True`）；强平/交割规则待实现
- 数据源：`Bar.open_interest` 字段已预留

## 4. 加密现货/永续（设计基线）

- 现货：T+0、全额、可小数下单（`qty_precision=3，如 0.001 BTC`）
- 永续：杠杆 + 资金费率 `funding_interval`（小时）+ 强平/清算（未实现）
- 24h 交易，`Instrument.trading_hours` 已支持 `(00:00, 23:59)`
- 订单簿类按 taker 立即成交处理

## 5. 跨市场通用建议（设计原则）

1. **结算与恒等式**：任何市场都应满足 `总权益 = 现金 + 持仓市值(+保证金占用)`，V2 的 `Account.total_asset` 已是统一口径。
2. **费用统一接口**：换市场只换 `FeeModel`，撮合成交逻辑无需改。
3. **日历/时段分离**：交易日历（`TradingCalendar`）+ 日内时段（`Instrument.trading_hours`）双层；跨市场用不同的 `calendar` 名 → `get_calendar(market)` 需补齐注册表。
4. **可做空即用 PositionSide.SHORT**：`Position`/`Trade` 已支持 side，现货端引擎当前忽略 SHORT。

## 6. 差异化实现路线（建议顺序）

| 优先级 | 任务 | 依赖 |
|---|---|---|
| P0 | 真实 A 股交易日历（含节假日） | calendar 注册表 |
| P1 | 严格涨跌停价（±10%/±20%）撮合 | matcher + Instrument |
| P2 | 期货简单撮合（保证金、T+0、做空） | 引擎支持 SHORT |
| P3 | 加密永续（杠杆、资金费、强平） | 账户保证金模型 |
| P4 | 多市场数据源与日历扩展 | 数据层 |
