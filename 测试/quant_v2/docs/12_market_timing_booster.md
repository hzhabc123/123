# Quant V2 底部/顶部区间增强模块

> 核心不是找单一神奇指标，而是：**多源独立证据共振 + 过滤假信号 + 概率思维 + 动态调整**。
> 底部/顶部永远是区域，不是点；以下方法只能提高概率，不能保证正确，必须结合仓位管理与止损。
> 本模块为技术分析教学，不构成投资建议。

## 1. 三大核心原则

1. **共振**：多源独立证据同时指向，才视为高概率区间。
2. **过滤**：用收盘/量能/回踩确认剔除假突破。
3. **概率**：输出命中率估计与仓位建议，而非绝对判断。

---

## 2. 方法体系（十三类信号源）

### 一、多周期共振与时间框架过滤

| 周期 | 作用 |
|------|------|
| 周线 | 定方向：周线在支撑/阻力附近，日线信号才更可信 |
| 日线 | 找区域：W底/M头、背离、量价异常 |
| 60/30分钟 | 找触发：精确到突破颈线、回踩不破、放量阳线 |
| 冲突处理 | 小周期服从大周期，信号降级或放弃 |
| 时间周期 | 斐波那契时间、节气/月初月末、财报窗口 |

### 二、多指标"独立类别"共振

> 不要只用 RSI+KDJ 这类同源动量指标。按类别分组，每类至少一个信号，**至少 3 类独立信号共振**才算高概率区间。

| 类别 | 底部信号 | 顶部信号 |
|------|---------|---------|
| 趋势 | 站上20日线、趋势线突破 | 跌破20日线、趋势线破位 |
| 动量 | RSI底背离、MACD金叉 | RSI顶背离、MACD死叉 |
| 量能 | 地量后放量阳线 | 天量滞涨、放量长上影 |
| 波动 | 布林下轨收回、ATR收缩 | 布林上轨回落、ATR放大 |
| 结构 | W底、头肩底、前低支撑 | M头、头肩顶、前高阻力 |
| 情绪 | 恐慌、破净、回购 | 狂热、减持、资金流出 |

### 三、成交量分布与筹码结构

- **Volume Profile**：找 POC、VAH、VAL，价格密集区易成支撑/阻力。
- **VWAP**：机构成本线，价格偏离后易回归。
- **筹码峰**：低位单峰密集易筑底，高位单峰密集易筑顶。
- **套牢/获利盘**：顶部获利盘>90%易抛压，底部套牢盘>90%易反弹。
- **大单/订单流**：CVD、Delta 背离，大单托底/压盘。

### 四、波动率与统计区间

- **ATR**：底部区间 = 前低 ± 1.5×ATR；顶部区间 = 前高 ± 1.5×ATR。
- **布林/肯特纳**：触及外轨 + 收回，作为区间边界。
- **历史波动率**：高波动区间放宽，低波动收窄。
- **Z-Score**：价格偏离均值 2σ 以上，回归概率增加。
- **期权 IV**：IV 高位常对应顶部恐慌，IV 低位常对应底部酝酿。

### 五、期权与衍生品数据

- **PCR**：看跌/看涨比率极值，常伴底部/顶部。
- **未平仓合约**：最大痛点、Gamma 暴露，影响到期日价格。
- **资金费率**：永续合约费率极高→顶部风险；极低→底部可能。
- **期货升贴水**：深度贴水常现底部，深度升水常现顶部。
- **期权偏度**：看跌偏度极高→市场恐慌，接近底部。

### 六、情绪与资金流

- 恐惧贪婪指数：极度恐惧关注底部，极度贪婪警惕顶部。
- 融资余额：快速下降后企稳→底部；快速上升后滞涨→顶部。
- 北向/主力资金：连续流入且价格不跌→底部；连续流出且价格不涨→顶部。
- ETF 申赎：大额申购→底部；大额赎回→顶部。
- 股债利差/ERP：股权风险溢价高位→底部区域；低位→顶部区域。

### 七、跨市场联动

- 股债汇商品：美债收益率、美元、原油、铜、黄金联动。
- 板块与龙头：龙头股先见底/见顶，板块跟随。
- 指数与个股：指数到支撑，个股信号更可靠。
- 全球市场：A股、美股、港股、日股共振时区间更有效。

### 八、价格行为与假突破过滤

- **收盘价确认**：突破颈线需收盘价站稳，而非盘中刺穿。
- **成交量确认**：突破需量 > 20日均量 1.5 倍。
- **回踩确认**：突破后回踩不破，二次买点。
- **假突破特征**：长上影、快速收回、量能不足。
- **K线组合**：早晨之星、看涨吞没；黄昏之星、看跌吞没。

### 九、基本面与估值分位

- PE/PB 分位：低于历史20%→底部区域；高于80%→顶部区域。
- 股息率：高于历史均值→底部信号。
- 盈利预期：盈利下调尾声→底部；上调尾声→顶部。
- 利率环境：降息周期利好底部，加息周期压制顶部。

### 十、事件与日历效应

- 财报/政策/宏观数据：事件落地后价格反应，利空出尽/利好兑现。
- 季节性：某些月份/季度有历史偏向。
- 期权到期日：最大痛点、Gamma 挤压。
- 指数调整：成分股调整带来资金流。

### 十一、量化回测与概率模型

- 特征工程：上述信号转为 0/1 特征。
- 分类模型：逻辑回归、随机森林、XGBoost，输出概率。
- 交叉验证：避免过拟合，滚动窗口回测。
- 概率校准：记录信号命中率，动态调整权重。
- 贝叶斯更新：先验概率 + 新信号 → 后验概率。
- 市场状态识别：ADX、Hurst、波动率状态，趋势/震荡市切换策略。

### 十二、仓位与风控增强

- 分批建仓/减仓：不要一次满仓。
- 凯利公式：根据胜率与赔率定仓位。
- 止损止盈：底部止损设前低下方，顶部止盈设颈线下方。
- 再平衡：区间内高抛低吸，降低持仓成本。
- 最大回撤控制：单笔亏损不超过总资金 2%。

### 十三、复盘与偏差控制

- 交易日志：记录信号、执行、结果。
- 清单化：每次按评分卡逐项打勾。
- 避免确认偏误：主动找反方证据。
- 定期统计：哪些信号组合命中率高，哪些是噪音。
- 动态权重：根据市场状态调整指标权重。

## 3. 增强评分卡（10 分制）

| 类别 | 底部得分 | 顶部得分 |
|------|---------|---------|
| 结构 | 前低/W底/头肩底 | 前高/M头/头肩顶 |
| 动量 | RSI底背离+MACD金叉 | RSI顶背离+MACD死叉 |
| 量能 | 地量后放量阳线 | 天量滞涨/长上影 |
| 波动 | 布林下轨收回/ATR收缩 | 布林上轨回落/ATR放大 |
| 情绪 | 恐慌/破净/回购 | 狂热/减持/资金流出 |
| 跨市场 | 股债汇商品共振 | 股债汇商品共振 |
| 基本面 | 估值低分位/高股息 | 估值高分位/低股息 |
| 期权 | PCR极高/深度贴水 | PCR极低/深度升水 |
| 时间 | 周期共振/事件落地 | 周期共振/事件落地 |
| 确认 | 收盘突破颈线+回踩不破 | 收盘跌破颈线+反抽不过 |

**判定规则：**
- ≥ 7 分 → 高概率区间，可分批操作。
- 5—6 分 → 关注，等待确认。
- ≤ 4 分 → 信号不足，放弃或仅观察。

## 5. 使用约束（必须遵守）

- 以上方法**只能提高概率，不能保证正确**；底部和顶部永远是**区域**，不是点。
- 必须结合**仓位管理**和**止损**执行。
- 多源信号冲突时，小周期服从大周期、信号降级或放弃，绝不硬凑共振。
- 输出必须附带 **概率估计** 与 **止损/目标位**，禁止只给方向不给风控。
- 本文档及提示词仅为技术分析方法论教学，**不构成任何投资建议**。
