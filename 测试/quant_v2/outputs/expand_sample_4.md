# 扩样本三列对照（batch_expand_sample）

**目的**：回答"框架是普遍无效，还是普遍只有低仓位 beta"。纯动量与评分卡各自跑三个版本——
策略实际、随机空仓（同样空仓比例、时点随机，检验择时时机）、固定低仓位（始终按该策略平均
持仓比例静态持仓，检验低仓位 vs 动态仓位）。

**样本**：2023-01-03 ~ 2024-12-31，4 标的，日线。lookback=30。

- 纯动量（A 类型，min_score=1）：`outputs/expand_momentum_4.json`
- 原评分卡（默认全因子，min_score=3）：`outputs/expand_scorecard_4.json`

## 结论（扩样本后）

1. **评分卡的 +2.77% 不可外推**：4 标的中 0 个跑赢随机空仓。茅台上的正超额是"低仓位 + 5 笔
   恰好落在反弹段"的样本特例，不是可重复的择时信号。用户此前对"评分卡择时成分更大"的期待，
   在扩样本上未得到支持——评分卡同样是低仓位 beta，且因交易极少而样本更脆弱。

2. **纯动量呈现"仓位策略"而非"择时策略"的完整画像**：
   - 下跌/震荡标的（600519、588000）靠空仓避跌 → 相对随机空仓占优
   - 上涨标的（300750、512880）靠低仓位避涨 → 相对随机空仓落后或勉强打平（300750 落后）
   - 净效果：能避跌、不能追涨 → 这是典型的低仓位 beta 特征，不是捕捉上涨的择时 alpha

3. **对主问题的回答**：既不是"普遍无效"，也不是"普遍只有低仓位 beta"——
   - 择时**时机**（何时空仓）在部分下跌/震荡标的有统计上占优的迹象（纯动量 3/4 跑赢随机空仓）
   - 但**幅度小且不稳定**，上涨标的反噬，且无显著性复核，不能宣称 alpha
   - 评分卡整体是失败的：低仓位 beta 都不算稳定，择时时机 0/4 重复

4. **下一步判断**：纯动量的"空仓避跌"在下跌标的有跨标的重复迹象，值得在本方向做显著性复核
   （bootstrap 跨标的）；评分卡路径应封存——5 笔样本 + 扩样本 0/4，结论是无择时信号。
