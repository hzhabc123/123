# 目标

描述一次完整交易从：

```text
市场数据到达
↓
策略分析
↓
风险审核
↓
仓位计算
↓
订单生成
↓
订单执行
↓
账户更新
↓
绩效统计
```

的完整调用流程。

# 一根K线完整处理流程

```text
DataFeed
    │
    │ get_next_bar()
    ▼
Bar Data
    │
    ▼
Strategy.on_bar()
    │
    │ 计算指标
    │ 计算信号
    ▼
Signal
    │
    ▼
RiskManager.check_order()
    │
    │ 检查:
    │ - 最大仓位
    │ - 最大回撤
    │ - 日亏损
    │ - 连续亏损
    ▼
Approved Signal
    │
    ▼
PositionSizer.calculate_size()
    │
    │ 计算下单数量
    ▼
Order
    │
    ▼
Broker.execute_order()
    │
    │ 扣手续费
    │ 加滑点
    │ 成交
    ▼
Trade
    │
    ▼
Portfolio.update()
    │
    │ 更新持仓
    │ 更新现金
    │ 更新净值
    ▼
Analyzer.record()
```

## Step 1

DataFeed读取K线

```python
bar = datafeed.get_next_bar()
```

返回：

```python

    "datetime": "...",
    "open": 100,
    "high": 110,
    "low": 95,
    "close": 108,
    "volume": 10000
}
```

---

## Step 2

策略收到K线

```python
strategy.on_bar(bar)
```

例如：

```python

```


# 回测主循环

```python
while datafeed.has_next():

    bar = datafeed.get_next_bar()

    strategy.on_bar(bar)

    signal = strategy.generate_signal()

    if signal:

        risk.check_order(signal)

        size = position_sizer.calculate_size()

        order = create_order()

        trade = broker.execute_order(order)

        portfolio.update(trade)

    analyzer.record()
```
